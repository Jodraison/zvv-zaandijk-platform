## 1. Leerdoelen

Na deze les kan de speelster:

1. **Herkennen** wanneer PAT-004 start op **onze linkerflank** (bal naar hun RB).  
2. **Zien** welke lijn het gevaarlijkst open is (binnenlijn).  
3. **Kiezen** de juiste first action: binnenkant sluiten, buitenom sturen.  
4. **Benoemen** de cue: **Binnenkant dicht**.  
5. **Begrijpen** dat dit **dezelfde** prioriteit is als op de rechterflank — niet een nieuwe leswet.

Niet het doel: PRESS-001 opnieuw uitleggen · Order #1 herhalen als boek · alle 22 rollen leren.

**Player title**

**Niet deze les:** omschakeling · laag blok · rechterflank (dat is Order #1).

## 3. Scan-opdracht

**Freeze** (T3): bal bij hun RB · binnenlijn zichtbaar · jij nog niet vastgezet.

**Scan (≤12 woorden):**

> Welke lijn is het gevaarlijkst open?

**Juiste scanfocus:** lijn RB → hun middenvelder (binnen / halfspace).

Optioneel: tik de binnenlijn (niet-scoring) — onthult **niet** het antwoord.

**Maximaal 3 scan-cues:**

1. Gaat de bal naar hun back?  
2. Staat er iemand vrij naar binnen?  
3. Ren jij recht op de bal of sluit je eerst die lijn?

---

## 4. Beslismoment

**Prompt (≤12 woorden):**

> Kies je eerste actie als linksbuiten.

**Eén scherm · één keuze · geen uitleg vóór keuze.**

| | Actie |
|--|-------|
| A | Recht naar de bal sprinten |
| B | Binnenkant sluiten, buitenom sturen |
| C | Terugzakken naast de middenvelders |

**Correct = B** (`PRESS-001` rang 1–2).

## 6. Uitvoering (PRESS-001 — kort)

Visueel tonen, niet voorlezen:

1. Aanloop **vanuit de binnenkant** van de escape (gebogen).  
2. Binnenlijn **dicht** vóór maximale baljacht.  
3. Buiten / touchline mag open — stuurkant.  
4. Rem vóór het duel; second press dekt de volgende binnenoptie.

**Gevolg juist:**

> Hun back kan niet naar binnen. Bal gaat terug of wijd. Ons team kan aansluiten.

**Uitleg correct (≤40 woorden):**

> Je sluit eerst de binnenlijn. Daardoor moet hun back naar buiten of terug. Ons team kan aansluiten. Eerst de lijn, dan het duel.

---

## 7. Veelgemaakte fouten

### A — Recht naar de bal

| | |
|--|--|
| Gevolg | Binnenlijn blijft open · hun middenvelder krijgt de bal |
| Uitleg (≤40) | Je rent recht op de bal. De pass naar binnen blijft open. Hun middenvelder komt vrij en onze druk valt weg. |
| Foutsoort | Verkeerde prioriteit + verkeerde aanloophoek |
| Fix | Eerst lijn, dan bal |

### C — Terugzakken

| | |
|--|--|
| Gevolg | Hun back krijgt tijd · opties blijven open |
| Uitleg (≤40) | Je zakt weg zonder de lijn te sluiten. Hun back krijgt tijd en speelt makkelijk verder. Dit moment vraagt gerichte druk. |
| Foutsoort | Trigger gemist / prioriteit opgegeven |
| Fix | First press mét binnenkant dicht |

## 8. Coaching

**Cue:**

# Binnenkant dicht

**Trainer:**

> Back krijgt ‘m — binnenkant dicht.

**Niet zeggen:** “pak de bal” · “wees slimmer” · “andere kant, andere regel” · lange theorie.

**Contrast (na keuze):**

| | FOUT | BETER |
|--|------|-------|
| Delta | Rechte sprint | Gebogen: binnen dicht |
| Rest | Zelfde start, pass, bal, teamintentie | Zelfde |

Toggle FOUT ↔ BETER. Labels pas **na** de beslissing.
