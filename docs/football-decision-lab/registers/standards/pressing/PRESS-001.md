## 2. Purpose

### Probleem

Zonder Standard wordt drukzetten gereduceerd tot enthousiasme, snelheid, de bal achterna lopen, of individuele improvisatie — waardoor de **binnenwaartse oplossing** open blijft.

### Oplossing — canonieke pressactie

PRESS-001 definieert uitsluitend:

1. binnenlijn / binnenwaartse oplossing **sluiten**;
2. tegenstander **naar buiten** sturen;
3. op de juiste **trigger** versnellen;
4. handelen met **minimale teamsteun**;
5. **niet starten / vertragen / afbreken / herstellen** wanneer voorwaarden ontbreken.

> Eerste prioriteit is **niet** zo snel mogelijk bij de bal komen.

## 3. Activation Context

### 3.1 Actief wanneer **alle** observeerbaar waar zijn

| # | Conditie | Observeerbaar |
|---|----------|---------------|
| A1 | Wedstrijdfase = georganiseerd **hoog of middenhoog drukzetten** tijdens hun **opbouw** | Team staat hoog/middenhoog georganiseerd; geen counterpress-chaos na eigen balverlies |
| A2 | Bal **onderweg naar** of **bij** hun **back** in flank-/opbouwzone | Passrichting of first touch van die back |
| A3 | Primary drukzetter = onze **balzijde-buitenspeler** (FIRST_PRESS) | Dichtstbijzijnde eigen buitenspeler aan balzijde |
| A4 | Binnenwaartse progressieve optie bestaat | Vrije/bedreigende binnen-middenvelder of halfspace-ontvanger bereikbaar vanaf die back |
| A5 | Minimale teamsteun aanwezig of startbaar (zie §9) | Cover achter/binnen en diepte niet afwezig als standbeelden |
| A6 | Force-plan = centrum beschermen, **buitenroute** mag als uitgang | Niet: first priority = buitenlijn dicht |

Ongeldige activatiezin: “wanneer we druk willen zetten.”

### 3.2 PRESS-001 is **niet** actief / mag niet worden doorgedrukt wanneer

| Situatie | Handelingsklasse (§10) |
|----------|------------------------|
| Omschakeling na **ons** balverlies | Buiten scope |
| Laag blok / geen press-organisatie | Buiten scope |
| Bal al **binnenwaarts** gespeeld vóór lane dicht kan | Niet starten als PRESS-001-succes; herstel buiten deze Standard-core |
| Press broken; numbers behind | Afbreken / herorganiseren — niet first-press doordrukken |
| Primary actor is niet balzijde-buitenspeler | Buiten scope |
| Inside-optie al strak gedekt én outside 2v1 dreigt (state shift) | **OPEN of andere prioriteit** — niet stilzwijgend PRESS-001 forceren |
| Minimale steun (§9) ontbreekt | **Niet starten** / niet doordrukken |

**Wet S1:** State-dependent — geen universele voetbalwet buiten §3.1.

## 4. Canonical Objective (vaste prioriteitsvolgorde)

Overal in deze Standard geldt **exact** deze volgorde:

| Rang | Doel |
|------|------|
| **1** | **Binnenwaartse oplossing sluiten** (passlijn/ruimte back → binnen-MV/halfspace) |
| **2** | **Tegenstander naar buiten sturen** (touchline/buitenroute als forced option) |
| **3** | **Tijd en ruimte verkleinen** op de bal (na 1–2; schaduwdruk / rem vóór duel) |
| **4** | **Voorspelbare vervolghandeling afdwingen** (terug / wide / long / duel — geen progressive inside) |
| **5** | **Balwinst proberen** — alleen na 1–4; **nooit** bewijs dat de press technisch correct was |

**Wet S2:** Process success zonder balwinst is mogelijk. Balwinst na fout proces is **geen** Standard-succes.

## 5. Spatial Definition — “Binnenkant dicht”

### 5.1 Object

| Term | Operationele betekenis |
|------|------------------------|
| **Binnenwaartse oplossing** | Voorwaarts-binnenwaartse pass of dribble-lijn van de **balhoudende back** naar de **dichtstbijzijnde progressieve binnen-ontvanger** (halfspace/centrum) |
| **Buitenroute** | Kanaal langs de **touchline** / buitenom — bewust **aangeboden** als forced exit |
| **Foutieve binnenroute** | Progressive inside pass/dribble die rang 1 had moeten blokkeren |

Reference labels (`opp.lb`→`opp.8`) zijn **voorbeelden**, geen Standard-IDs.

### 5.2 Ternaire toestand (toetsbaar)

| Toestand | Observeerbaar oordeel |
|---------|------------------------|
| **OPEN** | Back kan progressive inside spelen; first press snijdt de lijn niet; cover ontkent ontvanger niet |
| **GEDEELTELIJK GESLOTEN** | Lijn bemoeilijkt maar nog speelbaar (gat/hoek/timing); Standard-proces **nog niet** geslaagd |
| **GESLOTEN** | Progressive inside is onbespeelbaar of evident tweede keus door drukzetterhoek **en/of** inside cover; hoogste-waarde escape ≠ inside |

### 5.3 Relaties

| Actor | Vereiste relatie |
|-------|------------------|
| Drukzetter t.o.v. bal | Benadert vanaf de **binnenzijde van de escape** (inside-out), niet via de kortste rechte lijn naar de bal/tenen |
| Drukzetter t.o.v. binnenlijn | Bezet/snijdt de binnenwaartse oplossing **vóór** maximale baljacht |
| Binnen-ontvanger | Wordt ontkend/afgeschermd door minimale cover (§9) — niet genegeerd |

### 5.4 Spelersperspectief — controlepunt

De drukzetter (of trainer op video) stelt:

> “Als de back **nu** naar binnen speelt, is die bal nog speelbaar?”  
> **Ja** → binnenkant OPEN of GEDEELTELIJK.  
> **Nee** → GESLOTEN.

## 6. Approach Line

### 6.1 Vereist ruimtelijk resultaat (canoniek)

De aanloop is correct wanneer:

1. de binnenwaartse oplossing tijdens/na de run **GESLOTEN** raakt (§5.2);  
2. de **buitenroute** als forced option blijft;  
3. de drukzetter **niet** de kortste rechte lijn naar de bal kiest als die de binnenlijn openlaat.

### 6.2 Evidence-based uitvoeringskenmerken

| Element | Spec |
|---------|------|
| Start (relatief) | Balzijde, **press-ready**; **niet** al in tackle-range vóór trigger |
| Benaderingshoek | **Inside-out**: eerst lijn dichten, dan nadering van de back |
| Verboden | Rechte lijn naar bal/tenen die inside openlaat; overrun voorbij de lijn zonder rang 1; terugzakken zonder lijn te sluiten |
| Tempo | Positioneren → benaderen → **versnellen na trigger** → **afremmen** vóór duel (schaduwdruk) |

### 6.3 Curve-geometrie

| Claim | Status |
|-------|--------|
| Evidence toont **gebogen** pad als correcte contrast-uitvoering t.o.v. rechte sprint | Ondersteund |
| Exacte curve-straal / meters universeel voor alle fields | **OPEN** (`PO-APPROACH-01`) — niet als universele geometrie geclaimd |
| Exacte startcoördinaten | **OPEN** (OD-05) — resultaatregel “niet tackle-range vóór trigger” blijft toetsbaar |

## 8. Trigger Model

### 8.1 Hiërarchie (verplicht)

```text
1 POSITIONEREN  → press-ready; geen max sprint
2 BENADEREN     → micro-steps; nog geen full commit voorbij besluitpunt
3 VERSNELLEN    → alleen na primaire trigger
4 DOORDRUKKEN   → schaduwdruk; rem vóór duel; rang 1–2 behouden
```

### 8.2 Trigger-prioriteit

| Rang | Signaal | Rol |
|------|---------|-----|
| **Primair (canoniek)** | Bal is **onderweg naar** of wordt **ontvangen door** hun **back** (“back receives”) | Zonder dit: **niet versnellen** naar full press |
| **Ondersteunend** | Pass komt van build-partner (typisch centrale verdediger; exacte passer **OPEN** OD-06); ontvanger half-closed/closed naar touchline (**OPEN** exacte band OD-04) | Versterkt timing; vervangt primaire trigger niet |
| **Niet gecertificeerd in PRESS-001** | Generieke triggers (willekeurige “slechte touch”, “Nu!”-roep, etc.) zonder FDL-lock | Niet gebruiken als Standard-canon |

### 8.3 Trigger ontbreekt

→ Blijf in positioneren/benaderen. **Niet** doordrukken. Zie §10.

### 9.1 Minimum (observeerbaar) — zonder full teampress-handboek

De drukzetter mag **niet doordrukken** wanneer één van deze ontbreekt:

| # | Voorwaarde | Observeerbaar falen |
|---|------------|---------------------|
| T1 | **Inside cover** op de progressieve binnen-ontvanger (rol: dichtstbijzijnde centrale/balzijde mid — evidence “8”) | Ontvanger blijft vrij in de halfspace |
| T2 | **Diepte/rugdekking** achter first press (rol: balzijde back ± CV — evidence “RB/RCB”) | Grote ruimte achter drukzetter; makkelijk erachter |
| T3 | **Centrum-screen** niet verlaten als baljacht (rol: andere 6 — evidence “6 screens, niet op de bal”) | Centrale corridor wagenwijd open door iedereen naar bal |

## 10. Stop, Abort and Recovery

### 10.1 Handelingsklassen

| Klasse | Betekenis |
|--------|-----------|
| **NIET STARTEN** | Geen versnellen naar full press |
| **VERTRAGEN** | Benaderen/schaduw zonder full commit |
| **AFBREKEN** | Stop doordrukken; prioriteit verschuift naar herstel/organisatie |
| **HERSTEL** | Minimale recovery; detailrichting deels OPEN |

### 10.2 Regels per fouttoestand

| Toestand | Klasse | Handelingsregel |
|----------|--------|-----------------|
| Binnenkant OPEN / GEDEELTELIJK na commit | Afbakenen als **mislukt proces** | Corrigeer naar inside-out + steun; niet “baljacht goedpraten” |
| Vertrek te laat; back speelt al inside | **AFBREKEN** | Geen alsnog rechte jacht als PRESS-001-succes |
| Trigger gemist / geen back-receive | **NIET STARTEN** | Blijf positioneren |
| Steun T1–T3 ontbreekt | **NIET STARTEN** of **AFBREKEN** | Geen solo doordrukken |
| Tegenstander speelt **naar binnen** | **AFBREKEN** → herstel | PRESS-001 first-press doel gemist |
| Tegenstander speelt **terug** | Na gesloten binnenkant: **uitkomst OK** mogelijk | Behoud organisatie; second actions toegestaan |
| Tegenstander **passeert** drukzetter (buitenom) | **HERSTEL** | Goal-side recovery met dieptecover (RB/RCV-rol); exacte looplijnen **OPEN** `PO-ABORT-02` |
| Eerste druk uitgespeeld / press broken | **AFBREKEN** | Reorganiseer; niet hopeloos doorjagen |

### 10.3 OPEN (non-invented)

| ID | Vraag | Impact |
|----|-------|--------|
| PO-ABORT-01 | Numerieke max press-duur (seconden) | NON-BLOCKING als §10.2 gevolgd wordt |
| PO-ABORT-02 | Exacte herstelgeometrie na uitspelen buitenom | NON-BLOCKING refinement |

**Wet S3:** Zonder §10.2 is de Standard niet certificeerbaar. Met §10.2 is minimale abort-veiligheid aanwezig.

## 11. Observable Success Criteria

### PROCESS SUCCESS (vereist)

| ID | Criterium |
|----|-----------|
| P1 | Juiste start: press-ready; niet tackle-range vóór trigger |
| P2 | Juiste afsluiting: binnenkant **GESLOTEN** (§5.2) |
| P3 | Juiste benadering: inside-out ruimtelijk resultaat; geen verboden rechte baljacht |
| P4 | Juiste trigger: versnellen pas na primaire trigger |
| P5 | Correcte teamondersteuning: T1–T3 niet falend |
| P6 | Correcte stop/herstelkeuze volgens §10 wanneer nodig |

### OUTCOME SUCCESS (ondersteunend)

| ID | Criterium |
|----|-----------|
| O1 | Tegenstander speelt buitenom / along touchline |
| O2 | Tegenstander vertraagt onder druk |
| O3 | Tegenstander speelt terug |
| O4 | Voorspelbare vervolgbal (terug/wide/long/duel) — geen progressive inside |
| O5 | Bal wordt gewonnen |

**Expliciet:**

- Process success **zonder** balwinst = geldig Standard-succes.  
- Balwinst **na fout proces** = **geen** Standard-succes.

## 12. Failure Modes

| Fout | Zichtbaar gevolg | Correct gedrag | Taal |
|------|------------------|----------------|------|
| Rechte baljacht / binnenkant open laten | Progressive inside speelbaar | Inside-out; rang 1 eerst | Cue **Binnenkant dicht** (OD-001 OPEN) |
| Te vroeg max sprint | Timing weg; uitgespeeld | Positioneren → trigger → versnellen | Neutraal: “wacht de back-receive” |
| Te laat / trigger gemist | Ball already inside | Eerder herkennen; anders afbreken §10 | Neutraal: “te laat — herstel” |
| Niet press-ready / afstand te groot | Geen echte first press | Press-ready vóór trigger | Neutraal |
| Solo zonder T1–T3 | Centrum/diepte open | Steun mee; anders niet doordrukken | Bestaande termen: aansluiten / rugdekking |
| Happen / geen rem | Overrun; lane of duel weg | Schaduwdruk; rem vóór duel | Neutraal: “rem vóór duel” |
| Geen vervolg na first action | Geen second cover/herstel | Rem + inside cover + diepte | Neutraal |
| Buitenroute eerst dichten i.p.v. binnen | Centrum gepenetreerd | Rang 1→2 volgorde | **Binnenkant dicht** / buitenom sturen |
| Terugzakken zonder lijn | Tijd voor back; press collapses | First press met lane dicht | **Binnenkant dicht** |

Geen nieuwe LANG-ID. Geen impliciete OD-001 PASS.
