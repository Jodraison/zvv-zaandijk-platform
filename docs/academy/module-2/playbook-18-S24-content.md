# Playbook 18 — S2.4: Balverlies centraal

**Module 2 — Speelmodel 4-2-3-1** · **S2 — Wij verliezen de bal** · **FLAGSHIP**  
**Status:** Definitieve inhoud v1.0 · **FDPS v1.1**  
**Leestijd:** ± 12 minuten (🟢-pad ± 3 min) · **Woorden:** ~5.200 *(speelster)*  
**Voorkennis:** PB01–PB17

### Woorden — één keer uitgelegd

| Woord | Betekenis |
|-------|-----------|
| **Centraal** | **midden** van het veld — **as** · **niet** links/rechts |
| **As** | **midden** tussen onze CV — **niet** open laten |
| **Steekpass** | pass **tussen** onze linies · **recht** naar spits |
| **Restverdediging** | spelers **niet** bij bal — **dekken** **gat** |
| **Vertragen** | tegenstander **tijd** afnemen — **niet** blind sprinten |
| **Passlijn dicht** | **tussen** bal en vrije teammate — **in de weg** |

**PB18 vs PB17:** PB17 = **flank** · ruimte **buiten** · switch · recover. PB18 = **centrum** · ruimte **rondom as** · **steek** · **niet** dezelfde reactie.
