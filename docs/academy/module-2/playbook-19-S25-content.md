# Playbook 19 — S2.5: Balverlies achterin

**Module 2 — Speelmodel 4-2-3-1** · **S2 — Wij verliezen de bal** · **FLAGSHIP**  
**Status:** Definitieve inhoud v1.0 · **FDPS v1.1**  
**Leestijd:** ± 13 minuten (🟢-pad ± 3 min) · **Woorden:** ~5.300 *(speelster)*  
**Voorkennis:** PB01–PB18

### Woorden — één keer uitgelegd

| Woord | Betekenis |
|-------|-----------|
| **Achterin** | **eigen helft** · **dicht** bij **doel** — **niet** middenveld |
| **Overleven** | **geen** 100% kans **geven** — **samen** **doel** beschermen |
| **Vertragen** | **tijd** winnen — **niet** wild tackle |
| **Restverdediging** | spelers **niet** bij bal — **dekken** **gat** |
| **Tweede paal** | **verre** doelpaal — **niet** vergeten |
| **Looplijn** | **loop** van spits **or** **10** — **in de weg** |

**PB19 vs PB14/17/18:** PB14 = **algemeen** · PB17 = **flank** · PB18 = **centrum midden**. PB19 = **achterin** · **doel eerst** · **paniek → plan** · **niet** fout **direct** herstellen.
