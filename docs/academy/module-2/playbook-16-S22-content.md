# Playbook 16 — S2.2: Counterpressing

**Module 2 — Speelmodel 4-2-3-1** · **S2 — Wij verliezen de bal** · **FLAGSHIP**  
**Status:** Definitieve inhoud v1.0 · **FDPS v1.1**  
**Leestijd:** ± 12 minuten (🟢-pad ± 3 min) · **Woorden:** ~5.000 *(speelster)*  
**Voorkennis:** PB01–PB15

### Woorden — één keer uitgelegd

| Woord | Betekenis |
|-------|-----------|
| **Bal terugjagen** | **samen** direct proberen bal **terug** te winnen — **niet** blind sprinten |
| **Trigger** | **signaal** dat jagen **wél** slim is — **of** **niet** |
| **Eerste jager** | **dichtstbij** — **één** speler sprint **eerst** |
| **Tweede jager** | **2e** druk — **niet** iedereen tegelijk |
| **Passlijn dicht** | **tussen** bal en vrije teammate — **blokkeren** |
| **Tweede bal** | bal **hoog** · **verkeerd** · **wij** **winnen** |

**PB16 vs PB15:** PB15 = **compact blijven**. PB16 = **soms** compact **afbreken** — **samen** bal **terugjagen** — **alleen** op **trigger**.
