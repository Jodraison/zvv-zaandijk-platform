# Playbook 23 — S3.3: Hoog pressing

**Module 2 — Speelmodel 4-2-3-1** · **S3 — Tegenstander heeft de bal** · **FLAGSHIP**  
**Status:** Definitieve inhoud v1.0 · **FDPS v1.1**  
**Leestijd:** ± 14 minuten (🟢-pad ± 3 min) · **Woorden:** ~5.700 *(speelster)*  
**Voorkennis:** PB01–PB22

### Woorden — één keer uitgelegd

| Woord | Betekenis |
|-------|-----------|
| **Hoog pressing** | **samen** **dicht** op **hun** opbouw — **niet** solo sprint |
| **Trigger** | **signaal** om **tegelijk** te starten — **niet** zomaar |
| **Startsein** | **roep** **or** **trigger** zichtbaar — **iedereen** **weet** |
| **Schaduwdruk** | **dichtbij** · **curve** · **niet** tackle wild |
| **Passlijn dicht** | **tussen** bal en vrije teammate — **blokkeren** |
| **Pressing afbreken** | **stop** jagen · **blok** — **niet** hopeloos |

**PB23 vs PB16:** PB16 = **wij** verliezen bal · **terugjagen**. PB23 = **zij** bouwen op · **wij** **kozen** hoog druk · **triggers** · **niet** hetzelfde moment.

**PB23 vs PB20–22:** PB20–22 = **organiseren** · **wachten**. PB23 = **actief** druk · **startsein** · **elf** tegelijk.
