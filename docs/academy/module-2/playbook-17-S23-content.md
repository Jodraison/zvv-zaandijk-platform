# Playbook 17 — S2.3: Balverlies op de flank

**Module 2 — Speelmodel 4-2-3-1** · **S2 — Wij verliezen de bal** · **FLAGSHIP**  
**Status:** Definitieve inhoud v1.0 · **FDPS v1.1**  
**Leestijd:** ± 12 minuten (🟢-pad ± 3 min) · **Woorden:** ~5.100 *(speelster)*  
**Voorkennis:** PB01–PB16

### Woorden — één keer uitgelegd

| Woord | Betekenis |
|-------|-----------|
| **Flank** | **zijkant** van het veld — **links** **or** **rechts** |
| **Vertragen** | tegenstander **tijd** afnemen — **niet** altijd sprinten |
| **Restverdediging** | spelers **niet** bij bal — **dekken** **gat** achter |
| **Zwakke kant** | kant **ver** van bal — **niet** leeg laten |
| **Schuiven** | hele team **zelfde kant** op — **als één blok** |
| **Passlijn dicht** | **tussen** bal en vrije teammate — **in de weg** |

**PB17 vs PB16:** PB16 = **centraal** · **jagen or niet**. PB17 = **flank** · **één fout** mag **geen** **counter** worden — **rest** + **vertragen**.
