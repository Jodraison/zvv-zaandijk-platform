## 1. Missie

Wij schrijven **geen** lessen · handleidingen · voetbaltheorie.

Wij bouwen het **voetbalbrein** van onze speelsters.

Na iedere Playbook: **zaterdag aantoonbaar betere beslissingen** — omdat zij anders kijkt, denkt, beweegt, samenwerkt, communiceert en kiest.

| Niet einddoel | Wel einddoel |
|---------------|--------------|
| Kennis | **Gedragsverandering** |
| Begrijpen alleen | **Automatisch herkennen + handelen** |
| “Ik heb gelezen” | **“Deze wedstrijd heb ik al gespeeld”** |

## 2. De enige succesvraag

> **Wat doet deze speelster zaterdag anders dan vóór deze Playbook?**

Kan de auteur dit **concreet** en **observeerbaar** beantwoorden?

**NEE** → Playbook **onvoldoende** · niet publiceren.

Antwoord hoort in **Performance Prediction** (§4) — min. 10 gedragingen.

## 3. Het Performance Model

Elke Playbook moet de speelster door deze ladder leiden. **Niet eerder stoppen.**

```
IK LEES
    ↓
IK ZIE
    ↓
IK HERKEN
    ↓
IK BEGRIJP
    ↓
IK VOORSPEL
    ↓
IK KIES
    ↓
IK HANDEL
    ↓
IK HERKEN DE SITUATIE DE VOLGENDE KEER AUTOMATISCH
```

| Trede | Subordinate standaard | Toets |
|-------|----------------------|-------|
| Lees | WCPE · scan | Fragmenten |
| Zie | WVLP Laag 2 | Visuals |
| Herken | FLES · ACE triggers | Herkenningspunten |
| Begrijp | Waarom-ketens | Aha |
| Voorspel | WCPE v2.1+ | 2-sec voorspelling |
| Kies | Decision Model | MWP |
| Handel | WVLP Laag 3 Daadje | Toepassing zaterdag |
| Automatisch | **WPE** | Performance Prediction + Coach Observation |

## 4. Performance Prediction (verplicht)

**Plaatsing:** Na Learning Transfer · vóór Zone A of als dedicated blok na Curriculum Context.

**Formaat:** Niet “de speelster begrijpt…” — **“Vanaf zaterdag doet deze speelster…”**

**Minimum: 10 observeerbare gedragingen** — zichtbaar tijdens wedstrijd.

### Voorbeelden (archetype)

| # | Gedrag |
|---|--------|
| 1 | Scant eerder vóór ontvangst |
| 2 | Opent lichaam eerder naar veld |
| 3 | Praat eerder (“Man!” “Breed!” “Tussen!”) |
| 4 | Herkent pressing eerder |
| 5 | Ziet vrije speler / derde man eerder |
| 6 | Bewaakt restverdediging automatisch |
| 7 | Laat zich minder uit positie trekken |
| 8 | Denkt één actie vooruit |
| 9 | Begrijpt waarom tegenstander iets probeert |
| 10 | Beïnvloedt actief teamgenoten (stem + beweging) |

**Regel:** Elke gedraging = **werkwoord + context + observeerbaar**.

```yaml
performance_prediction:
  - "Scant schouder vóór eerste touch in opbouw"
  - "..."
  count_min: 10
```

## 5. Visual Performance Protocol

**Boven WVLP v1.0** — vervangt/versterkt 4-vraag-test waar WPE actief is.

**Voor iedere visual — 7 vragen. Eén zwak = visual verdwijnt.**

| # | Vraag |
|---|-------|
| V1 | Welk **leerprobleem** lost deze visual op? |
| V2 | Welke **verkeerde beslissing** voorkomt deze visual? |
| V3 | Welke **juiste beslissing** stimuleert deze visual? |
| V4 | Waarom is **tekst** onvoldoende? |
| V5 | Welke **speelster** (positie/rol) profiteert direct? |
| V6 | Welke **wedstrijdsituatie** wordt ineens begrijpelijk? |
| V7 | Welke **cognitieve belasting** verdwijnt hierdoor? |

**Decoratie = FAIL.** WVLP TYPE 1–7 blijft van toepassing; WPE 7-vraag is **extra gate**.

## 6. Wedstrijdsimulatie (verplicht patroon)

**Iedere belangrijke uitleg-eenheid** eindigt met simulatie **vóór** de uitleg (Socratisch).

### Vast template

```
━━━━━━━━━━━━━━━━━━
STOP. Stel je voor.
━━━━━━━━━━━━━━━━━━

Minuut [X]. Stand [X-X].
[Situatie in 2–4 zinnen — concreet]

Jij bent [rol in dit moment].

Wat zie jij?
Waarom?
Wat gebeurt er als jij niets doet?
Welke opties heb je?
Welke keuze maakt ZVV?
Waarom juist die keuze?
Wie profiteert?
Wie krijgt hierdoor ruimte?
Welke tegenstander moet nu kiezen?
Wat gebeurt er daarna?

[Pas nu: uitleg / ketting / visual]
```

**Minimum per Playbook:** 5 volledige simulaties · 20 verkorte varianten in fragmenten.

## 7. 22-speler principe

**Iedere belangrijke situatie** — meerdere perspectieven.

### Onze elf + kern tegenstander

Keeper · LCV · RCV · LB · RB · L6 · R6 · 10 · LW · RW · Spits  
+ hun spits · hun 10 · hun vleugel · hun back  
+ trainer (wat wil hij zien?) · optioneel: scheidsrechter

**Niet:** alleen “wat doet de back?”  
**Wel:** elke beslissing beïnvloedt **keten** — zichtbaar maken.

**WVLP TYPE 5** (22-perspectieven) = verplicht implementatie bij systeem-entries · aanbevolen alle entries.

```markdown
|---|----------------------|--------------|

```

**Minimum 8 observaties** — gekoppeld aan Performance Prediction (1:1 waar mogelijk).

**Niet:** “speelsters zijn slimmer”. **Wel:** “scan vóór touch in 7/10 opbouwmomenten”.
